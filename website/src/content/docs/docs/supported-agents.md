Here's the list of every agent that sablier can track time for. If you want to add a new one, see [contributing](/docs/contributing/).

## Claude code

No config needed, just run `sablier claude`

## Codex

No config needed, just run `sablier codex`. \
Codex might warn you about new hooks, you need to approve them for tracking to work.

## Opencode

No config needed, just run `sablier opencode`.
